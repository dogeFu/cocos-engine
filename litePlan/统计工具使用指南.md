# 统计工具使用指南

## 命令说明

### 1. `npm run stats` - 查看统计（不保存）
只统计当前代码，不保存报告文件。

```bash
npm run stats
```

**输出示例**：
```
================================================================================
📊 Cocos Engine 代码统计报告
================================================================================

📝 代码行数统计
────────────────────────────────────────────────────────────────────────────────
TypeScript: 314,113 行 (1244 文件)
C++:        478,969 行 (2005 文件)
────────────────────────────────────────────────────────────────────────────────
总计:       793,082 行 (3249 文件)
```

---

### 2. `npm run stats:save` - 统计并保存
统计当前代码，并保存报告到 `litePlan/stats-report.json`。

```bash
npm run stats:save
```

**输出**：
```
📄 报告已保存到: /Users/kay/Git/cocos-engine/litePlan/stats-report.json
```

---

### 3. `npm run stats:diff` - 统计并对比
统计当前代码，与之前的报告对比，并保存新报告。

```bash
npm run stats:diff
```

**输出示例**：
```
================================================================================
📊 Cocos Engine 代码对比报告
================================================================================
对比基准: 2026/4/11 00:11:01

📝 代码行数对比
────────────────────────────────────────────────────────────────────────────────

────────────────────────────────────────────────────────────────────────────────

📦 TypeScript 模块对比
────────────────────────────────────────────────────────────────────────────────
physics                0 行      -23,085 [已删除]
profiler                 785 行      -200 (-20.3%)
```

## 使用场景

### 场景1：裁剪前建立基准
```bash
# 1. 保存当前状态作为基准
npm run stats:save

# 2. 执行裁剪操作（如删除 physics 模块）
# ... 删除代码 ...

# 3. 统计并对比裁剪效果
npm run stats:diff
```

---

### 场景2：持续监控裁剪进度
```bash
# 每次裁剪一个模块后
npm run stats:diff

# 输出会显示：
# - 删除了多少代码
# - 哪些模块被删除
# - 哪些模块被修改
# - 打包体积变化
```

---

### 场景3：快速查看当前状态
```bash
# 只查看，不保存
npm run stats
```

---

## 对比报告说明

### 颜色标识
- 🟢 **绿色**：代码减少（好事）
- 🔴 **红色**：代码增加（需要关注）
- ⚪ **灰色**：无变化

### 状态标识
- `[已删除]`：模块完全删除
- `[新增]`：新增的模块
- 无标识：模块存在但代码量变化

## 报告文件位置

所有报告保存在：`litePlan/stats-report.json`

**报告格式**：
```json
{
  "timestamp": "2026-04-11T00:15:46.000Z",
  "summary": {
    "totalLines": 793082,
    "totalFiles": 3249,
    "buildSize": 65298234
  },
  "details": {
    "typescript": { ... },
    "cpp": { ... },
    "build": { ... }
  }
}
```

## 典型工作流程

### Phase 1：建立基准
```bash
npm run stats:save
```

### Phase 2：删除模块
```bash
# 删除 Profiler 模块
rm -rf cocos/profiler

# 查看效果
npm run stats:diff
```

### Phase 3：继续裁剪
```bash
# 删除 Terrain 模块
rm -rf cocos/terrain

# 查看效果
npm run stats:diff
```

### Phase 4：验证最终结果
```bash
# 最终统计
npm run stats:save
```

---

## 注意事项

1. **首次使用**：如果没有 `stats-report.json`，`stats:diff` 会提示无法对比
2. **保存时机**：建议在每次重大修改后保存一次报告
3. **对比基准**：对比总是基于最近一次保存的报告
4. **文件位置**：报告文件会提交到 Git，方便团队共享
