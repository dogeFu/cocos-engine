# 3D 渲染系统模块分析

## 模块作用

3D 模块是 Cocos Creator 的 3D 渲染核心,负责所有 3D 图形元素的渲染和管理。它提供了网格(Mesh)、材质(Material)、光照(Light)、相机(Camera)等 3D 渲染组件,支持 PBR 材质、骨骼动画、地形系统、天空盒等高级特性,是 3D 游戏开发的基础。

### 主要功能领域

1. **网格渲染** - MeshRenderer 和 SkinnedMeshRenderer
2. **材质系统** - Material 和 Effect 系统
3. **光照系统** - 各种光源组件
4. **相机系统** - Camera 组件和渲染目标
5. **骨骼动画** - SkinnedMeshRenderer 和骨骼系统
6. **地形系统** - Terrain 组件

## 设计理念

### 1. PBR 材质系统

3D 模块采用基于物理的渲染(PBR)材质系统,实现真实感的渲染效果。

**PBR 核心概念:**
- **Albedo**: 反照率(基础颜色)
- **Metallic**: 金属度
- **Roughness**: 粗糙度
- **Normal**: 法线贴图
- **AO**: 环境光遮蔽

**材质设计:**
```typescript
class Material extends Asset {
    effectAsset: EffectAsset;
    technique: number;
    passes: Pass[];
    
    setProperty(name: string, value: any): void {
        // 设置材质属性
        for (const pass of this.passes) {
            pass.setProperty(name, value);
        }
    }
    
    getProperty(name: string): any {
        // 获取材质属性
        return this.passes[0].getProperty(name);
    }
}
```

### 2. 网格渲染系统

3D 模块使用 MeshRenderer 组件渲染 3D 网格。

**渲染流程:**
```
MeshRenderer 组件
    ↓
获取 Mesh 和 Material
    ↓
创建 Model 对象
    ↓
提交到渲染场景
    ↓
渲染管线处理
```

**网格数据:**
```typescript
class Mesh extends Asset {
    // 顶点数据
    positions: Vec3[];
    normals: Vec3[];
    uvs: Vec2[];
    tangents: Vec4[];
    
    // 索引数据
    indices: number[];
    
    // 子网格
    subMeshes: SubMesh[];
    
    // 包围盒
    boundingBox: AABB;
}
```

### 3. 光照系统

3D 模块支持多种类型的光源,实现丰富的光照效果。

**光源类型:**
- **Directional Light**: 平行光(太阳光)
- **Point Light**: 点光源
- **Spot Light**: 聚光灯
- **Sphere Light**: 球形光
- **Tube Light**: 管状光

**光照实现:**
```typescript
class DirectionalLight extends Component {
    color: Color;
    intensity: number;
    staticSettings: StaticSettings;
    
    update(dt: number): void {
        // 更新光照数据
        const light = this._light;
        light.color = this.color;
        light.intensity = this.intensity;
        light.direction = this.node.worldRotation * Vec3.UNIT_Z;
    }
}
```

### 4. 骨骼动画系统

3D 模块包含完整的骨骼动画系统,支持复杂的角色动画。

**骨骼动画组件:**
- **Skeleton**: 骨骼数据
- **SkinnedMeshRenderer**: 蒙皮网格渲染器
- **Animation**: 动画组件

**蒙皮计算:**
```typescript
class SkinnedMeshRenderer extends MeshRenderer {
    skeleton: Skeleton;
    skinningRoot: Node;
    
    update(dt: number): void {
        // 更新骨骼矩阵
        const bones = this.skeleton.joints;
        const bindPoses = this.skeleton.bindPoses;
        
        for (let i = 0; i < bones.length; ++i) {
            const boneNode = bones[i];
            const bindPose = bindPoses[i];
            
            // 计算蒙皮矩阵
            Mat4.multiply(this._boneMatrices[i], boneNode.worldMatrix, bindPose);
        }
        
        // 更新到 GPU
        this._boneTexture.update(this._boneMatrices);
    }
}
```

### 5. 相机系统

3D 模块的相机系统支持多种投影模式和渲染目标。

**相机属性:**
```typescript
class Camera extends Component {
    // 投影模式
    projection: number;  // PERSPECTIVE 或 ORTHO
    
    // 透视投影
    fov: number;         // 视场角
    near: number;        // 近裁剪面
    far: number;         // 远裁剪面
    
    // 正交投影
    orthoHeight: number; // 正交高度
    
    // 渲染设置
    priority: number;    // 渲染优先级
    visibility: number;  // 可见性掩码
    clearColor: Color;   // 清屏颜色
    targetTexture: RenderTexture;  // 渲染目标
}
```

## 核心组件详解

### 1. MeshRenderer 网格渲染器

**职责:**
- 渲染静态网格
- 管理材质
- 处理阴影

**关键属性:**
- `mesh`: 网格资源
- `materials`: 材质数组
- `receiveShadow`: 是否接收阴影
- `castShadow`: 是否投射阴影

### 2. SkinnedMeshRenderer 蒙皮网格渲染器

**职责:**
- 渲染骨骼动画网格
- 处理蒙皮计算
- 支持骨骼混合

**关键属性:**
- `skeleton`: 骨骼资源
- `skinningRoot`: 骨骼根节点
- `mesh`: 网格资源

### 3. Light 光源组件

**职责:**
- 提供光照数据
- 支持多种光源类型
- 处理阴影

**关键属性:**
- `color`: 光源颜色
- `intensity`: 光照强度
- `type`: 光源类型

### 4. Camera 相机组件

**职责:**
- 定义渲染视角
- 控制渲染参数
- 管理渲染目标

**关键属性:**
- `fov`: 视场角
- `near`: 近裁剪面
- `far`: 远裁剪面
- `projection`: 投影模式

## 代码示例

### 网格渲染

```typescript
import { MeshRenderer, Mesh, Material } from 'cc';

// 获取网格渲染器
const renderer = node.getComponent(MeshRenderer);

// 设置网格和材质
renderer.mesh = mesh;
renderer.setMaterial(material, 0);

// 设置阴影
renderer.receiveShadow = true;
renderer.castShadow = true;
```

### 创建光源

```typescript
import { DirectionalLight, PointLight } from 'cc';

// 创建平行光
const dirLight = node.addComponent(DirectionalLight);
dirLight.color = Color.WHITE;
dirLight.intensity = 1.0;

// 创建点光源
const pointLight = node.addComponent(PointLight);
pointLight.color = Color.RED;
pointLight.intensity = 2.0;
pointLight.range = 10.0;
```

### 相机控制

```typescript
import { Camera } from 'cc';

const camera = node.getComponent(Camera);

// 设置透视投影
camera.projection = Camera.Projection.PERSPECTIVE;
camera.fov = 60;
camera.near = 0.1;
camera.far = 1000;

// 设置正交投影
camera.projection = Camera.Projection.ORTHO;
camera.orthoHeight = 10;

// 设置渲染目标
camera.targetTexture = renderTexture;
```

// 获取蒙皮网格渲染器

## 模块关联

### 上游依赖

3D 模块依赖:
- **Core**: 数学库、对象管理
- **Scene Graph**: 节点系统
- **Rendering**: 渲染管线
- **GFX**: 图形接口
- **Asset**: 资源加载
- **Animation**: 动画系统

### 下游依赖

3D 模块被以下模块使用:
- **Physics**: 物理组件挂载到 3D 对象
- **Terrain**: 地形系统基于 3D 渲染

## 性能优化策略

### 1. LOD 系统
- 根据距离切换网格细节
- 减少远处对象的顶点数

### 2. 遮挡剔除
- 剔除被遮挡的对象
- 减少不必要的渲染

### 3. 批处理
- 合并相同材质的对象
- 减少 Draw Call

### 4. 骨骼优化
- GPU 蒙皮
- 骨骼纹理压缩
- 骨骼数量限制

## 总结

3D 模块是 Cocos Creator 3D 游戏开发的基础,其设计体现了:

1. **PBR 渲染**: 基于物理的真实感渲染
2. **组件化设计**: 网格、光照、相机独立管理
3. **骨骼动画**: 完整的骨骼动画解决方案
4. **性能优化**: LOD、遮挡剔除、批处理等优化策略
5. **扩展性**: 支持自定义材质和渲染效果

理解 3D 模块的设计理念,对于开发高质量的 3D 游戏至关重要。
